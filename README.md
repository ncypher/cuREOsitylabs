# CuREOsity Labs LLC

Company website for CuREOsity Labs, an independent technology workshop in REO Town, Lansing, Michigan.

## Website

`index.html` is a complete, dependency-free static website with embedded brand artwork. Deploy it directly using GitHub Pages, Cloudflare Pages, or any static host.

The project workbench runs entirely in the visitor’s browser and downloads a text brief. It does not transmit submissions or include a contact inbox.

## Intended domain

cureositylabs.com

For GitHub Pages, enable Pages for the default branch / root, then set the custom domain in Pages settings and configure DNS at the domain provider. Add the CNAME file when that hosting choice is confirmed. For Cloudflare Pages, connect this repository and serve the root directory with no build step, then add the custom domain.
